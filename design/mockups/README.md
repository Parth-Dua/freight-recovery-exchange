# Early mockups (Claude design canvas)

Source files of the first-pass screens drawn on a Claude design canvas: carrier console (Sailings, Sailing detail,
Pricing, Agent activity, Risk) and market view (Disruption, Negotiation, X-ray, Allocation). They superseded the
ChatGPT mood images and were in turn superseded by the Paper designs. Kept for reference and for the Devpost
design-process story. `/_blob/...` image links point at the canvas's uploaded ship drawing (see `../assets/ship.svg`).
